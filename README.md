# Autobot 
Ein 2D-Unity-Projekt über ein Strategiespiel mit Mechaniken von einem Auto-Battler.

------------------------------------------------------------------------

## Projekt
Dieses Projekt wurde für das Modul **5FSC0XD101** am **SAE Institute Hannover** erstellt.

Es beinhaltet Aufgaben: Spieleprototyp, Alpha, Beta, Goldmaster, Projektreflexion.

Entwicklungs-Zeitraum: **11.09.2025 - 05.03.2026**
- Update am 12.05.2026

Aufgaben:
- Entwurf von GDD
- Aufgaben- und Zeitplanung
- Entwicklung eines funktionsfähigen Prototyps basierend auf einer Grundidee
- Entwicklung von Core-Feature-Complete Demo
- Entwicklung von Feature- & Content-Complete Demo
- Entwicklung von Gold-Build
- Erstellung von Projektreflexion

------------------------------------------------------------------------

## Spiel-Features
- PvP Gameloop inkl. Shop- und Kampfphasen
- Grundstruktur von Spieleinheiten und Währungssystem mit Scriptable Object
- Interaktionen mit Spielobjekten und UI
- Kampfablauf mit FSM
- Animation und SFX inkl. Sound mit FMOD
- Cutscenes
- Replay System
- Katalog
- Tutorial
- KI-Spieler
